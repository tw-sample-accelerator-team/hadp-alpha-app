# Intent: Delivery Commercial Governance

The product owner's intent for release 1:

- Give Delivery Managers and CLT members an account-level CGM Coach that aggregates financial performance and signals across all projects under an account they are entitled to.
- Highlight below-target or falling CGM, its key cost drivers and the project-level evidence behind it, with optimization suggestions (such as personnel grade adjustments or leverage changes) and their expected CGM impact.
- Let the user record which suggestions to adopt as a plan: action items, intended changes, an owner per action and an expected CGM improvement target.
- Never execute an intervention or operational change automatically: the system suggests, records and measures; people act.
- Track each action's execution, compare actual CGM against the plan before and after, and show clearly when planned improvement was not realized.
- Show the account's governance history: execution status, ownership and effect, so users can see which measures worked and which were not adopted.
- Run on Google Cloud: project `alpha-dev-80ca`, region `us-central1`.
